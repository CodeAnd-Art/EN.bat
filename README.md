# EN – VM Friend

## Açıklama
EN, sanal makine içinde çalıştırılmak üzere tasarlanmış **interaktif bir kaos simülasyonudur**. Kullanıcıyla konuşur, sinirlenir, küfürlere tepki verir, sorular sorar ve en ufak hatada VM’nin kernelini siler.

## Özellikler
- 108+ modüler dosya yapısı
- VM / ana cihaz ayrımı (ana cihazda çalışmaz)
- Sinir seviyesi sistemi (:) → D:< → Kernel ye)
- Konuşma chat + küfür/hakaret/yakınlaşma tespiti
- Görsel bozulma ve ekran patlamaları
- Çok dilli destek (Türkçe, İngilizce, Almanca, Fransızca)
- Kendi kendini tamir mekanizması
- Gerçek kernel silme (sadece VM içinde)
- Log sistemi

## Uyarı
Bu yazılım **sadece sanal makine içinde test edilmelidir.**
Ana cihazda çalıştırılırsa kendini durdurur ve uyarı verir.
